# MemeRadar 0.2.0 — démonstration Windows V2

Neuf pages françaises : tableau de bord, veille, personnes, conversations, événements, tokens, alertes, sources et paramètres. Le scénario fictif Nébula comprend 63 publications et quatre tokens, avec une horloge partagée persistante, conversation partielle, preuves sociales, graphiques par chaîne/adresse et contrôles de risque expliqués. Les anciens exemples restent distincts.

Les préférences, notes et alertes sont locales. Les mots-clés/personnes sont évalués sur le scénario ; les autres alertes restent des exemples pédagogiques. Les budgets, quotas et pannes sont simulés. Aucun appel API, compte, secret ou outil de développement nécessaire sur le PC.

Télécharger **MemeRadar-0.2.0-Windows-x64-installer.zip**, choisir **Extraire tout**, puis ouvrir l’EXE inclus. Windows 10/11 x64 uniquement. Le ZIP contient l’installateur, le guide et l’empreinte ; SHA256SUMS.txt couvre aussi les deux fichiers publiés.

Fermer l’ancienne version avant installation ; sauvegarder `%APPDATA%\MemeRadar` complet. Le paquet conserve les formats locaux et le même nom d’application. Pas de mise à jour automatique. L’ancienne publication 0.1.0 reste disponible.

Paquet non signé : Windows peut afficher un éditeur inconnu. La démonstration n’apporte ni serveur HTTP authentifié, ni collecte réelle, ni notification externe. Les services privés testés ne sont pas raccordés à l’interface. Aucun portefeuille ou achat ; aucune recommandation financière. Voir le guide et la matrice fonctionnelle dans le dépôt.
