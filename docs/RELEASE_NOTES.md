MemeRadar 0.1.0 pour Windows 10/11 x64 — première édition de démonstration hors ligne.

Télécharger le fichier `MemeRadar-0.1.0-Windows-x64-installer.zip`, choisir **Extraire tout**, puis ouvrir le fichier `.exe` contenu dans le dossier extrait. L'assistant est en français. Aucun outil de développement, Node.js, Docker, compte ou clé API nécessaire.

L'application inclut trois scénarios fictifs, huit tokens factices, les vues événements/tokens/alertes/sources/paramètres, les explications des indicateurs, le rejeu temporel et les préférences locales. Les connecteurs de données réelles restent à développer.

Le paquet n'est pas signé par un certificat d'éditeur. Les empreintes SHA-256 sont fournies. Ne désactivez pas les protections de votre ordinateur. Voir les limites et les résultats de validation dans la documentation du dépôt.
